## What this repository is for

Somebody searching this name is usually following a technical thread, not looking for a wallet download, and this page is written for that reader. The repository holds source. It does not carry an installer, it does not publish the account's articles, and it is not where a first-time visitor should begin.

The account's product is Terra Station Wallet, a desktop application whose releases are recorded in their own repository. The code here belongs to the supporting set around that product, and it is published openly under Apache-2.0 so that the terms are clear before anyone spends time on it.

What this page refuses to do is describe the implementation. That refusal is worth explaining rather than hiding: a feature summary on a marketing page is written once and read for months, while the code changes underneath it. The reader then makes a decision on a sentence that nobody rechecked. The source, the commit history and the issue tracker are three sources that stay accurate without anyone maintaining a second account of them.

So the page does three things instead. It places the repository in the account, it names the licence without paraphrasing it, and it sends readers who wanted the wallet to the hubs where the wallet is actually explained. Anything beyond that would be a claim the reader cannot verify from where they stand.

## Who it is for

- You are evaluating this repository and want the licence, the maintaining account and the support channel in one place.
- You are reading the account as a whole and want each repository's role stated without a description of its internals.
- You depend on something connected to it and need to know whether the terms permit what you are doing.
- You followed a link expecting a product page and want to be redirected to the wallet without a detour.

## Common first questions

### What is this repository in relation to the wallet?

It is adjacent code in the same account, not a component the reader installs. The wallet is a separate repository with its own releases, and its installers do not come from here.

### Can I redistribute it?

Apache-2.0 permits it, subject to that licence's conditions, which include keeping the notices. Read the licence file in the repository rather than relying on the badge or on this sentence.

### Why is there no technical overview?

Because an overview would be a second, unchecked description of code that already describes itself. The account keeps its writing budget for the wallet's readers, where a page can actually help somebody finish a task.

### Where do I ask a question?

In the issue tracker on this repository. Nothing in this account asks for a password, a recovery phrase or a private key, and a request for one is not from here.

## Before you depend on it

Read the licence, look at how the repository is maintained, and confirm the default branch before you pin anything. Three checks, and each answers a question a dependency decision turns on rather than a question about style.

If you came for the wallet, this page is a detour. The install hub starts with the file and the release it belongs to, which is where an installation actually begins.
